Q1. Explain why a table in Second Normal Form (2NF) might still suffer from update anomalies, and state the condition required to achieve Third Normal Form (3NF).

[25 Marks]

Even if a relation is in 2NF (no partial dependencies on a composite primary key), it can still contain transitive dependencies where a non-key attribute depends on another non-key attribute (e.g., Student_ID → Dept_ID → Dept_Head).

If we update the Department Head for a department, we must update multiple rows, causing update anomalies. To reach 3NF, every non-prime attribute must be non-transitively dependent on the primary key ("nothing but the key").

👁️ MODEL ANSWER KEY — QUESTION 1 Full Credit: 25 pts

✓ Must identify Transitive Dependency ($A \rightarrow B \rightarrow C$) as the root cause of redundancy in 2NF.
✓ Must state 3NF rule: Relation is in 2NF and no non-prime attribute is transitively dependent on the primary key (or for every $X \rightarrow Y$, $X$ is a superkey or $Y$ is prime).

Q2. Write an SQL query on the Orders(OrderID, CustomerID, OrderTotal, Status) table to list all CustomerIDs who have placed more than 3 completed orders with a combined total exceeding $1,500.

[40 Marks]
SELECT CustomerID, COUNT(OrderID), SUM(OrderTotal)
FROM Orders
WHERE Status = 'Completed' AND COUNT(OrderID) > 3 AND SUM(OrderTotal) > 1500
GROUP BY CustomerID;
👁️ MODEL ANSWER KEY — QUESTION 2 Deduct 10 pts if aggregate is inside WHERE
SELECT CustomerID, COUNT(OrderID) AS OrderCount, SUM(OrderTotal) AS TotalSpent
FROM Orders WHERE Status = 'Completed'
GROUP BY CustomerID
HAVING COUNT(OrderID) > 3 AND SUM(OrderTotal) > 1500;

Q3. A campus LAN is assigned the CIDR block 192.168.10.0/26. Calculate the subnet mask in dotted decimal notation, total IP addresses, and maximum usable host addresses.

[35 Marks]

• Prefix /26 means 26 network bits (11111111.11111111.11111111.11000000) → Subnet Mask = 255.255.255.192

• Remaining host bits = 32 - 26 = 6 bits. Total addresses = 26 = 64 addresses.

• Usable hosts = 64 - 2 (Network ID .0 & Broadcast .63) = 62 usable hosts.

👁️ MODEL ANSWER KEY — QUESTION 3 Full Credit: 35 pts

✓ Subnet Mask: 255.255.255.192 (10 pts)
✓ Total Addresses: $2^{32-26} = 2^6 = 64$ (10 pts)
✓ Usable Hosts: $64 - 2 = \mathbf{62}$ hosts, citing Network (.0) and Broadcast (.63) reservation (15 pts).
